# banco-web-app-Frontend

Plataforma web de un sistema bancario en la cual un usuario puede registrarse, enviar transferencias y ver su perfil de usuario.

Esta aplicación cuenta con una arquitectura desacoplada utilizando **React** con **Vite** para el frontend y **Java con Spring Boot** para el backend.


## 🛠️ Tecnologías Utilizadas

### Frontend
- **React** 
- **Vite**
- **React Router Dom** 
- **Axios** 
- **Bootstrap**

### Backend
- **Java**
- **Spring Boot**
- **Spring Security** / **JWT** 
- **Spring Data JPA** 
- **H2 database**
- **Maven**
